# AI Passport 玩法：六爻占卜 & 每日穿衣

把 FoloToy AI Passport 变成一台随身的两用小工具：**六爻占卜**与**每日穿衣**。

## 这是什么

- **六爻占卜**：开机进入功能选择，先选所问之事（事业 / 财运 / 感情……），填上当天的日期，再长按按键蓄力、松手掷出三枚铜钱——掷六次成卦。铜钱分背面与字面，数几个背面定这一爻；蓄力的轻重也参与随机，所以同一个动作摇两次也不会完全一样。卦成之后给出卦名、卦象与简要解读。
- **每日穿衣**：选好日期，按当日干支五行给出当天的幸运色与穿搭建议。

## 怎么玩

1. 启动页用上下键选择「六爻占卜」或「每日穿衣」，按 OK 进入。
2. 六爻：选所问之事 → 填日期（上下键调年 / 月 / 日，OK 确认）→ 长按蓄力摇铜钱、松手掷出，重复六次成卦 → 看解卦。任意页长按 OK 回功能选择页。
3. 每日穿衣：选日期 → 看当日五行色建议。
4. 长时间不操作会进入待机：功能选择页只把屏幕调暗；六爻 / 穿衣内则显示对应的待机图（八卦环 / 五行色环），按任意键点亮继续。

## 2.0 更新了什么

- 新增「每日穿衣」玩法：按干支五行给出每日幸运色与穿搭建议。
- 六爻占卜整体打磨：更顺的起卦流程，卦象与解读呈现更清楚。
- 启动页待机改为只调暗背光，不再显示六爻待机图。
- 移除原有的开发演示菜单（启动页长按 OK 不再进入演示页），界面更干净、更适合直接发布。
- 待机只压暗背光，更省电。

## 构建与烧录（开发者）

- 固件基于 ESP-IDF，工程在 `fw/`。
- 本地模拟器在 `sim/`，无需设备即可预览界面。
- 烧录：`idf.py build && idf.py flash -p <端口>`。

## 目录

- `fw/` 固件（ESP-IDF 工程）
- `sim/` 本地模拟器
- `ui/` LVGL 界面
- `algo/` 六爻与五行算法
- `assets/` 图片资源
- `tools/` 辅助脚本
